Le projet

À propos d'EcoSort

EcoSort est une application web pédagogique qui combine scraping e-commerce et Deep Learning pour aider à identifier la bonne consigne de tri d'un produit courant.

Comment ça marche

01

Recherche

Le produit saisi est recherché sur Jumia (avec repli automatique sur un catalogue de démonstration).

02

Sélection

L'utilisateur choisit le produit correspondant parmi les résultats affichés.

03

Analyse IA

Un modèle de Deep Learning (MobileNetV2) détermine la catégorie de tri.

04

Résultat coloré

L'écran se colore selon la poubelle correspondante — impossible de se tromper.

Stack technique

  • TensorFlow / Keras — CNN & Transfer Learning
  • BeautifulSoup / Requests — scraping Jumia
  • Flask — interface web
  • Docker — containerisation
